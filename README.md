# Haile-Manas Academy Library

A single-page school library site: searchable catalog, borrowing and reservations, study-room booking, digital shelf, events and a reading goal. Plain HTML, CSS and JavaScript, no build step.

## Run it
Open `index.html` in a browser, or enable GitHub Pages (Settings, Pages, deploy from the `main` branch root).

## Files
- `index.html` the whole site
- `assets/` school photos and logo

Catalog, hours and events are sample content. Loans, bookings and questions are stored in the visitor's browser only.
